# Intraday preview

Manual, independent, educational experiment. It uses quote-only NH PLUG and, in models mode, the existing four OpenRouter model IDs. It never receives a broker/order key, an official database connection, or a GitHub personal token. No scheduled trigger is installed.

1. GitHub Actions → intraday-preview → Run workflow → main → probe / now. This checks the same-session complete NH regular-session 5-minute grid for SPY, QQQ, DIA, IWM without requesting AI responses. Review the run receipt first. The chart contract only supports labels anchored at 09:30; missing, shifted, stale or invalid data blocks the test. Confirm the provider's actual candle labeling and data-use rights before treating this as a published methodology.
2. After the probe verifies live data, select models / now for a single prospective trial with an estimated USD 0.15 ceiling including retries. The four models receive the same snapshot hash and isolated clean virtual accounts ($100,000 each, long-only, 20% cap per symbol, simulated 1 bp fee and 5 bp slippage per side). No actual orders, no official scores, no automated batch or carried positions yet. Market data is not copied to logs/artifacts; the receipt contains hash, timestamps, per-model status, validated intents and estimated simulation costs only.
3. Named checkpoints in Eastern time: open 09:40, morning 11:00, afternoon 14:00, preclose 15 minutes before the actual close (15:45 normally; 12:45 on a 13:00 early close). After a five-minute start window the named checkpoint is missed and is not replayed. On a half day the afternoon checkpoint does not occur. No decision before ten minutes after open or with less than ten minutes before close. “Now” is an ad-hoc checkpoint, not an earlier named checkpoint.
4. A missing or invalid model blocks all fills. Once all outcomes are recorded, the next 5-minute period strictly after the shared lock is the only fill candidate. Wait for its completion and verify exact prices, regular session, available volume and risk limits. Never substitute an earlier/later quote. Read the Actions receipt to distinguish all HOLD, blocked, and simulated. Existing season and public site are not modified by preview execution.

Status: actual NH minute labels and live four-provider round require manual verification. This isolated runner is not yet an ongoing four-round leaderboard or a replacement for the official morning engine.
